# OSA 项目网站 · 当前交互品质愿望（2026-11-20 · 交互品质参考）

OSA 项目站首先要让读者理解方法、论文图表、可查看的交互演示以及可核验的证据边界；视觉与交互必须服务科研阅读，不能把未经验证的研究结果或模型效果伪装成已完成。

用户希望进一步打磨：研究入口、图形/方法演示、语言选择与其它可操作元素的 **hover、键盘 focus、触控反馈**；图标的视觉大小、相对位置和空间节奏应帮助区分信息层级，不造成阅读跳动。重要信息在没有鼠标或动画时仍可理解。

**目前参考（非永久要求）：** [nuro.dev](https://nuro.dev/) 在 2026-11-20 所见的悬停反馈与图标/布局处理。这只是启发，不是克隆指令、固定 CSS/像素/时长标准或唯一优选；未来出现更合适的学术交互实例，允许并鼓励采用更好方案。

将来实施时应先核对当前 Astro 组件与设计 token，做适当的低成本原型；真实检查桌面及 440×956 手机、键盘焦点、触控、prefers-reduced-motion、无布局偏移与溢出，并保持论文图、数值、结果来源、中英文和 SEO 的真实性。**这是一份待实施的 Wish，不是功能交付或生产授权。**
